# Dynamic Time Warping

In time series analysis, dynamic time warping (DTW) is one of the algorithms for measuring similarity between two temporal sequences. DTW aligns two sequences (qi → cj), along a common time axis usually with Euclidean cost.

### Description

## Keyword Spotting:

Digitizing historical manuscripts for cultural heritage preservation. 
Textual content: searching and browsing scanned page images
Widely unsolved for historical handwriting
Keyword spotting is a “shortcut”: identify individual search term

## Signature Verification:

A biometric technique that uses characteristics of a person's signature (including pressure, pen lifts, speed and direction of pen strokes) to authenticate identity.
