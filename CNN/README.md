## Authors

Meisam Asgari Jirhandeh, Seyedeh Sharareh Mirzargar, Maxence Feller, Yanisa Butphrom, Atefeh Fakhari

## Description

Train and test a basic CNN on the MNIST dataset. Optimize learning rate (typically in the range [0.001, 0.1]). Optimize number of training iterations. Plot a graph showing the accuracy on the training set and the test set, respectively, with respect to the training epochs. Perform the random initialization several times and choose the best network during testing.
